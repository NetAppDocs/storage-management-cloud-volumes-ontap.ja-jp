= Cloud Volumes ONTAP の自動化オプションについて
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
DevOpsチームは、データセンターのランタイム環境のセットアップと管理を自動化するために、さまざまなツールを使用しています。NetApp Console に加えて、NetApp Console API、ONTAP CLI 手順、Ansible や Terraform などの自動化ツールを含む、これらのテクノロジーのいくつかを Cloud Volumes ONTAP の自動化に使用できます。外部自動化ツールは一般的に、Infrastructure as Code（IaC）設計に基づいています。

 https://labondemand.netapp.com/["ラボ オンデマンド"^]を使用して、Cloud Volumes ONTAP の自動化を練習します。



[[netapp-console-apis]]
== NetApp Console API

NetApp Consoleは、Cloud Volumes ONTAPリソースをプログラムで管理するために使用できるREST APIを提供します。APIは、Cloud Volumes ONTAPシステムの作成と管理、およびAmazon Web Services（AWS）、Microsoft Azure（Azure）、Google Cloudへのアグリゲートとボリュームの追加などの操作をサポートします。利用可能なAPI呼び出しは、クラウド プロバイダおよびシングルノード構成と高可用性（HA）構成を含む展開タイプによって異なります。

Cloud Volumes ONTAP の API ワークフローを使用して、一般的なデプロイメントとそれに続くストレージ管理を自動化できます。ワークフローには、デプロイの準備、システムの構築、ストレージの管理などが含まれており、AWS、Azure、Google Cloud といったクラウド プロバイダ固有のワークフローも用意されています。

[[ontap-cli]]
== ONTAP CLI

ONTAP CLIは、Cloud Volumes ONTAPのいくつかの管理タスクに使用できます。使用可能な手順とコマンドは、機能およびクラウド プロバイダによって異なります。ONTAP CLIまたはONTAP System Managerを使用して、Cloud Volumes ONTAPをアップグレードしないでください。アップグレードはNetApp Consoleから実行してください。

[cols="2,2,3"]
|===
| アクティビティ | CLI手順またはコマンド | 参考資料 


| Cloud Volumes ONTAP の暗号化キー管理を設定します。 | AWS KMS、Azure Key Vault、またはGoogle Cloud KMS コマンド（ONTAP CLI）  a| 
link:task-aws-key-management.html["AWS KMSキー管理の設定"] link:task-azure-key-vault.html["Azure Key Vault のキー管理を構成する"] link:task-google-key-manager.html["Google Cloud KMSキー管理の設定"]



| イベント管理システム（EMS）のイベント送信先と経路を設定します。 | ONTAP CLI の EMS 構成コマンド | link:task-configure-ems.html["EMSの設定"] 


| 既存の Cloud Volumes ONTAP クラスタに NTP サーバーを設定します。 | `cluster time-service ntp server create` | link:task-sync-time.html["NTPサーバーの設定"] 


| ストレージ効率を無効にしたボリュームを作成する場合は、データ圧縮を無効にしてください。 | ONTAP CLI ボリューム効率化コマンド  a| 
link:concept-flash-cache.html["ストレージ効率化オプションを確認する"] link:reference-limitations-aws.html["AWSストレージ効率の制限事項を確認する"]



| 追加のLUNを作成します。 | ONTAP CLIでのLUN作成コマンド | link:task-create-volumes.html["ボリュームと追加のLUNを作成する"] 


| WORM を無効にしたボリュームを作成するか、該当する場合は SnapLock ボリュームの Snapshot コピーを作成します。 | ONTAP CLI でのボリュームとスナップショットの管理コマンド  a| 
link:concept-worm.html["WORMストレージの管理"] link:reference-worm-snaplock.html["WORMストレージのSnapshotコピーを作成する"]



| データ損失イベント発生後、問題が解決されるまでデータへのアクセスを防止するために、NVFAIL の動作を設定します。 | ONTAP CLI での NVFAIL 設定コマンド | link:concept-write-speed.html["NVFAILの設定"] 


| Azure シングルノード環境における SnapMirror レプリケーショントラフィックを分離します。 | ONTAP CLI ネットワーキングとSnapMirrorコマンド | link:task-segregate-snapmirror-azure.html["Azure でSnapMirrorトラフィックを分離する"] 
|===
詳細については、 https://docs.netapp.com/us-en/ontap-cli/man.html["ONTAP CLI リファレンスガイド"^]を参照してください。

== Terraform
