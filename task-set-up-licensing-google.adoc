[role="lead"]
Google CloudのCloud Volumes ONTAPでどのライセンスオプションを使用するかを決定したら、システムを作成する際にそのオプションを選択する前に、いくつかの設定手順を完了する必要があります。



[[freemium]]
== フリーミアム

最大 500 GiB のプロビジョニング容量でCloud Volumes ONTAP を無料で使用するには、Freemium オファリングを選択してください。link:concept-licensing.html#packages["フリーミアムプランの詳細"] 。

.手順
. 左側のナビゲーション メニューから、*ストレージ > 管理* を選択します。
. 「Systems」ページで、「Add System」を選択し、NetApp Consoleの手順に従います。
+
.. 「詳細と認証情報」ページで、「認証情報の編集」>「サブスクリプションの追加」を選択し、プロンプトに従ってGoogle Cloud Marketplaceの従量課金制オファリングにサブスクライブします。
+
マーケットプレイスのサブスクリプションでは、プロビジョニングされた容量が500GiBを超えない限り、料金は発生しません。超えた場合、システムは自動的にlink:concept-licensing.html#packages["エッセンシャルパッケージ"]に変換されます。

.. コンソールに戻ったら、課金方法のページにアクセスして「*Freemium*」を選択します。
+
image:screenshot-freemium.png["Cloud Volumes ONTAPシステムを作成する際の Freemium オプションのスクリーンショット。"]





link:task-deploying-gcp.html["Google Cloud でCloud Volumes ONTAP を起動するための手順をご覧ください"] 。



[[capacity-based-license]]
== 容量ベースのライセンス

容量ベースのライセンスでは、Cloud Volumes ONTAPの容量1TiB単位で料金を支払うことができます。容量ベースのライセンスは、_パッケージ_：EssentialsまたはProfessionalとして提供されます。

Essentials および Professional パッケージは、次の消費モデルまたは購入オプションで利用できます。

* NetApp から購入したライセンス（Bring-Your-Own License または BYOL）
* Google Cloud Marketplace からの時間単位の従量課金制（PAYGO）サブスクリプション
* 年間契約


link:concept-licensing.html#capacity-based-licensing["容量ベースのライセンスについて詳しく見る"] 。

これらの消費モデルをそれぞれ使い始めるには、次のセクションの手順に従ってください。



[[byol]]
=== BYOL

NetAppからライセンス (BYOL) を購入して前払いすることで、任意のクラウド プロバイダーにCloud Volumes ONTAPシステムを導入できます。


NOTE: NetApp は、BYOLライセンスの購入、延長、更新を制限しています。詳細については、 https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/whats-new.html#restricted-availability-of-byol-licensing-for-cloud-volumes-ontap["Cloud Volumes ONTAPの BYOL ライセンスの利用制限"^]を参照してください。

.手順
. https://www.netapp.com/forms/sales-contact/["ライセンスを取得するには、 NetApp の営業担当者にお問い合わせください。"^]
. https://docs.netapp.com/us-en/console-setup-admin/task-adding-nss-accounts.html#add-an-nss-account["NetAppサポートサイトのアカウントをNetApp Consoleに追加します"^]
+
コンソールは NetApp のライセンス サービスに自動的にクエリを実行し、 NetAppサポート サイト アカウントに関連付けられているライセンスの詳細を取得します。エラーがなければ、コンソールはライセンスを追加します。

+
Cloud Volumes ONTAP でライセンスを使用するには、事前にコンソールからライセンスが利用可能な状態になっている必要があります。必要であれば、link:https://docs.netapp.com/us-en/console-licenses-subscriptions/task-manage-data-services-licenses.html#add-a-license["コンソールにライセンスを手動で追加する"]。

. 「システム」ページで、「システムの追加」を選択し、手順に従ってください。
+
.. 「詳細と認証情報」ページで、「認証情報の編集」>「サブスクリプションの追加」を選択し、プロンプトに従ってGoogle Cloud Marketplaceの従量課金制オファリングにサブスクライブします。
+
お客様がNetAppから購入したライセンスが常に最初に課金されますが、ライセンス容量を超過した場合、またはライセンス期間が満了した場合は、時間当たりのマーケットプレイス料金が課金されます。

.. コンソールに戻ったら、課金方法ページにアクセスして容量ベースのパッケージを選択します。
+
image:screenshot-professional.png["Cloud Volumes ONTAPシステムを作成する際の Professional オプションのスクリーンショット。"]





link:task-deploying-gcp.html["Google Cloud でCloud Volumes ONTAP を起動するための手順をご覧ください"] 。



[[paygo-subscription]]
=== PAYGOサブスクリプション

クラウド プロバイダーのマーケットプレイスからのオファーをサブスクライブして、時間単位で支払います。

Cloud Volumes ONTAPシステムを作成すると、コンソールに、Google Cloud Marketplace で利用可能な契約に加入するように求めるメッセージが表示されます。そのサブスクリプションは課金システムに関連付けられます。同じサブスクリプションを追加のシステムにも使用できます。

.手順
. 左側のナビゲーション メニューから、*ストレージ > 管理* を選択します。
. 「システム」ページで、「システムの追加」を選択し、手順に従ってください。
+
.. 「詳細と認証情報」ページで、「認証情報の編集」>「サブスクリプションの追加」を選択し、プロンプトに従ってGoogle Cloud Marketplaceの従量課金制オファリングにサブスクライブします。
.. コンソールに戻ったら、課金方法ページにアクセスして容量ベースのパッケージを選択します。
+
image:screenshot-professional.png["Cloud Volumes ONTAPシステムを作成する際の Professional オプションのスクリーンショット。"]





link:task-deploying-gcp.html["Google Cloud でCloud Volumes ONTAP を起動するための手順をご覧ください"] 。


TIP: アカウントに関連付けられている Google Cloud Marketplace のサブスクリプションは、「設定」>「認証情報」ページから管理できます。 https://docs.netapp.com/us-en/console-setup-admin/task-adding-gcp-accounts.html["Google Cloud の認証情報とサブスクリプションを管理する方法を学びます"^]



[[annual-contract]]
=== 年間契約

年間契約を購入して、 Cloud Volumes ONTAP の料金を毎年支払います。

.手順
. 年間契約を購入するには、 NetApp の営業担当者にお問い合わせください。
+
この契約は、Google Cloud Marketplace でプライベート オファーとして入手できます。

+
NetApp がプライベート オファーを共有した後、システム作成中に Google Cloud Marketplace からサブスクライブするときに年間プランを選択できます。

. 「システム」ページで、「システムの追加」を選択し、手順に従ってください。
+
.. 「詳細と認証情報」ページで、「認証情報の編集」>「サブスクリプションの追加」を選択し、画面の指示に従って Google Cloud Marketplace の年間プランに登録してください。
.. Google Cloudで、アカウントに共有されている年間プランを選択し、*Subscribe*を選択します。
.. コンソールに戻ったら、課金方法ページにアクセスして容量ベースのパッケージを選択します。
+
image:screenshot-professional.png["Cloud Volumes ONTAPシステムを作成する際の Professional オプションのスクリーンショット。"]





link:task-deploying-gcp.html["Google Cloud でCloud Volumes ONTAP を起動するための手順をご覧ください"] 。



[[keystone-subscription]]
== Keystoneサブスクリプション

Keystoneサブスクリプションは、成長に応じて支払うサブスクリプション ベースのサービスです。link:concept-licensing.html#keystone-subscription["NetApp Keystoneサブスクリプションの詳細"] 。

.手順
. まだ購読していない場合は、 https://www.netapp.com/forms/keystone-sales-contact/["ネットアップに連絡"^]
. コンソールユーザーアカウントを1つ以上のKeystoneサブスクリプションで承認するには、mailto:ng-keystone-success@netapp.com[NetAppにお問い合わせ]ください。
. NetAppがお客様のアカウントを承認したあと、link:task-manage-keystone.html["Cloud Volumes ONTAPで使用するためにサブスクリプションをリンクします"]。
. 「システム」ページで、「システムの追加」を選択し、手順に従ってください。
+
.. 課金方法を選択するように求められたら、 Keystoneサブスクリプションの課金方法を選択します。
+
image:screenshot-keystone.png["Cloud Volumes ONTAPシステムを作成する際のKeystoneサブスクリプション オプションのスクリーンショット。"]

+
link:task-deploying-gcp.html["Google Cloud でCloud Volumes ONTAP を起動するための手順をご覧ください"] 。







[[node-based-license]]
== ノードベースのライセンス

ノードベースのライセンスは、Cloud Volumes ONTAPの旧世代のライセンスです。ノードベースのライセンスはNetAppから購入できました（BYOL）。ノードベースのライセンスは現在、特定のケースでのみ更新可能です。詳細については、以下を参照してください：

* https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/whats-new.html#end-of-availability-for-node-based-licenses["ノードベースライセンスの提供終了"^]
* https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/concept-licensing.html#end-of-availability-of-node-based-licenses["ノードベースライセンスの提供終了"^]
* https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/task-convert-node-capacity.html["ノードベースのライセンスを容量ベースのライセンスに変換する"^]
