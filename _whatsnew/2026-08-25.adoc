=== Azure におけるオーストリア東部およびベルギー中部リージョンのサポート

Cloud Volumes ONTAP 9.12.1 GA以降を、AzureのAustria East（austriaeast）およびBelgium Central（belgiumcentral）リージョンにデプロイできるようになりました。以下のデプロイメントタイプがサポートされています：

* シングルノード
* ローカル冗長ストレージ（LRS）を使用した単一可用性ゾーンにおける高可用性（HA）
* ゾーン冗長ストレージ（ZRS）を使用した複数可用性ゾーンにおける高可用性（HA）


サポートされているすべての地域のリストについては、 https://bluexp.netapp.com/cloud-volumes-global-regions["Azure のグローバル地域マップ"^] 。
