=== プライベートモードデプロイメントにおけるGoogle Infrastructure Managerのサポート

Cloud Volumes ONTAP 9.16.1 以降では、Google Cloud での新しいプライベートモード展開において、 https://docs.cloud.google.com/deployment-manager/docs/deprecations["Cloud Deployment Manager"^]（DM）の代わりに https://docs.cloud.google.com/infrastructure-manager/docs/overview["Google Cloud Infrastructure Manager"^]（IM）がサポートされるようになりました。Google は、より高度な Infrastructure Manager を優先して、インフラサービスとしての Deployment Manager を廃止する予定です。

2026年2月25日以降、Cloud Volumes ONTAPは新規および既存のプライベートモード環境の導入にInfrastructure Managerを使用します。基本的なワークフローは、状況によって異なります：

[cols="1,4,1,1,1,1"]
|===
| シナリオ | アクション | エージェント用の新しいAPI | エージェントの新しい権限 | Cloud Volumes ONTAP向けの新しいGoogle Cloud API | ドキュメントリソース 


| 既存のエージェントとプライベートモードでの既存の導入 | NetApp Support Siteからインストーラをダウンロードし、ホストにエージェントを手動でインストールして、Consoleエージェントを最新バージョンにアップグレードします。これにより、Infrastructure Manager APIを使用できるようになります。次に、既存のCloud Volumes ONTAPシステムを、Infrastructure Managerを使用するように変換します。  a|

プライベートモードの展開では、Cloud Volumes ONTAPがInfrastructure Managerの使用を開始できるように、いくつかの設定変更を行う必要があります。 https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/reference-networking-gcp.html#infrastructure-manager-configuration-in-private-mode-or-protected-environments["プライベートモードまたは保護された環境でのインフラストラクチャマネージャの構成"^]を参照してください。
