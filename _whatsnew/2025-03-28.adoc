=== Cloud Volumes ONTAP 9.14.1 に対してプライベートモードの展開が有効になりました

AWS、Azure、Google Cloud でCloud Volumes ONTAP 9.14.1 をプライベート モードでデプロイできるようになりました。プライベート モードは、Cloud Volumes ONTAP 9.14.1 のシングル ノードと高可用性 (HA) の両方の展開で有効になります。

プライベートモードの展開に関する詳細については、https://docs.netapp.com/us-en/console-setup-admin/concept-modes.html#restricted-mode["BlueXPの展開モードについて学ぶ"^]を参照してください。
